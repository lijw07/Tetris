SIMPLE FALLING BLOCKS — VERSION 2

Open preview.html to see the scene, the asset layout and play the new music.

This version uses flat colors, square corners, thin borders and a plain background.
The music is an original 20-second loop at 96 BPM, using only a short melody and
soft bass. No drums, reverb or third-party samples.

Assets: seven 24px colored blocks, seven piece previews, one ghost outline,
10x20 board, panel, two button states, pause/sound icons and a four-frame clear
flash. SVG originals and PNG exports are provided. Reuse the plain panel and
buttons for menus and dialogs; complete interactive menus are not implemented.

The clear flash has four 24x24 frames horizontally. Play once at 16 fps.
Music: mono 16-bit PCM WAV, 44,100 Hz; loop samples 0 to 882,000 (exclusive).

This is review artwork and audio, not an integrated Godot scene. The .gdignore
file keeps the review folder out of Godot's import system. The first version and
the existing game configuration were not changed.

Editable sources are in source/. Python audio generation requires NumPy;
PNG export requires Node.js with sharp. Fonts use system Menlo/monospace;
PNG exports preserve the reviewed text appearance. See manifest.json for details.
